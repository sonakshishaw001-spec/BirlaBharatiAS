The problem

AI code generators write game code blind. They produce syntactically valid code that still results in blank screens, broken game loops, untriggered colliders, and impossible win states, because nothing actually plays the game to check.

Our solution

ForgeLoop closes the loop: it generates the game, runs an automated playtest to verify core mechanics actually work, and when something breaks, it diagnoses and patches its own code, then re-tests, without a person stepping in.

What you can do

Prompt to playable

One natural-language prompt generates a full working 2D game, no manual setup.

Automated playtesting

A testing harness checks movement, collisions, scoring and win/loss states on its own.

Self-healing pipeline

Runtime errors are diagnosed and patched automatically, then re-verified, live in front of you.

How it works

  1. Describe the game

    Type a one-line prompt, like "a platformer where you collect coins and avoid spikes."

  2. Watch it play itself

    The system generates code, then a playtesting bot runs the game to check it actually works.

  3. Watch it fix itself

    If something breaks, the agent diagnoses the bug, patches the code, and re-tests automatically.
